# Phone Directory Management System

A simple Python-based application that allows users to store, search, view, and delete phone contacts using file handling.

## Overview

This project is developed using Python concepts taught in the VITyarthi Python Essentials course. It provides a digital phone directory where contact information is saved in a text file.

## Features

- Add a new contact
- Search contact by name
- View all saved contacts
- Delete a contact
- Automatic data saving using file handling

## Technologies Used

- Python 3
- Dictionaries
- Functions
- Loops & Conditions
- File Handling

## Project Structure

PhoneDirectory/
- main.py
- directory.py
- storage.py
- contacts.txt
- README.md
- statement.md
- requirements.md

## How to Run

1. Open the project folder.
2. Run `main.py`.
3. Choose an option from the menu.
4. Contacts are stored in `contacts.txt`.

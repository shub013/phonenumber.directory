# Project Requirements

## Functional Requirements

1. The system shall allow users to add a new contact.
2. The system shall search contacts using the contact name.
3. The system shall display all saved contacts.
4. The system shall delete an existing contact.
5. The system shall save contact details in a text file.

## Non-Functional Requirements

- User-friendly terminal interface
- Fast search and retrieval of contacts
- Reliable data storage using file handling
- Modular and maintainable Python code
